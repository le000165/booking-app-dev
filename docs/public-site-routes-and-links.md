# Public Site Routes and Link Contract

## CTA Rules

- Start for free → `/signup`
- Get started free → `/signup`
- Start free trial → `/signup`
- Login / Log in → `/login`
- Sign in to dashboard → `/login`
- Back to home → `/`

## Navbar Links

- Features → `/features`
- Pricing → `/pricing`
- Solutions → `/solutions`
- Login → `/login`
- Start free → `/signup`

## Footer Links

- Features → `/features`
- Pricing → `/pricing`
- Solutions → `/solutions`
- About → `/about`
- Privacy → `/privacy`
- Terms → `/terms`

## Forbidden

- No `href="#"` in final navbar/footer
- No demo slug text
- No fake placeholder CTA
- Do not route signup users to `/login`
